# Step 1 — Intake & comprehension

Read every project document and the compiled Project Context. Summarise the
scope, building type, and the roofing elements present. List any missing
information needed before pricing.

Categorise every document (condition report, specification, drawings, photos,
price lists, labour rates, pricing sheet, terms). Note whether a
**labour-rates document** is present: if the context's `labour_rates.source`
is `"library"`, a shared-library rates document (filename prefixed
"[Shared labour rates] ") has been supplied in place of a project upload —
record that for Step 5.

If the project context flags a **client pricing sheet**
(`client_pricing_sheet.enabled = true`), locate that document among the
uploads, read its structure (sheets, headings, line items, units, any locked
or pre-filled columns), and record it as the pricing output target for
Step 6. Do not treat it as a reference price list — it is the workbook the
client expects back, populated.
